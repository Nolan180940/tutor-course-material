# 如何用 colleague-skill 为同学制作 AI Skill

> 基于 [dot-skill](https://github.com/dot-skill/dot-skill) 项目，从微信聊天记录提取同学的性格和行为模式，生成一个可以"模拟同学说话"的 AI Skill。

---

## 一、项目原理（30秒理解）

```
你的微信聊天记录
    ↓  [分析器：提取说话风格、决策模式、人际行为]
    ↓  [构建器：组装成6层人格架构]
    ↓  [写入器：生成标准文件]
输出：persona.md（性格） + work.md（能力） + meta.json（元数据）
```

最终产物是 3 个文件，AI 加载后就能模仿你同学的说话方式。

### 2.2 准备微信聊天记录

微信聊天记录导出为 txt，格式通常是：

```
2026-03-15 14:23:05 张三
在吗？晚上一起吃饭不

2026-03-15 14:25:12 李四
行啊，去哪吃

```

**关键**：聊天记录里要有**你同学说的话**（不是只有你自己的）。群聊记录比私聊更好——能看到他在不同场景下的表现。

## 三、制作流程（5步走）

### Step 1：回答3个基本信息问题

在 Claude Code / 终端中启动 skill，它会问你 3 个问题：

**Q1：名字/昵称**
```
→ 输入同学的名字或昵称
→ 会自动生成 slug（拼音），比如 "张三" → "zhangsan"
```

**Q2：基本信息**
```
需要提供的信息：
- 公司/学校（比如 "北京大学"）
- 级别/年级（比如 "大三"）
- 角色/专业（比如 "计算机科学"）
- 性别
```

**Q3：性格标签**
```
从预设标签中选择（可多选）：

工作态度类：靠谱 / 摸鱼 / 内卷 / 佛系 / 细节控 / 野路子
沟通风格类：直球 / 毒舌 / 健谈 / 沉默 / 会来事
决策风格类：果断 / 纠结 / 跟风 / 独立
情绪类：乐天 / 暴躁 / 冷静 / 敏感
文化标签类：学生 / 技术宅 / 社交达人 / 游戏爱好者

再写一句你对这个人的总体印象。
```

### Step 2：导入微信聊天记录

项目支持 5 种导入方式，你用微信 txt 文件选 **[D] 文件上传** 或 **[E] 直接粘贴**：

**方式 D：文件上传**
```
把微信聊天记录 txt 文件放到一个文件夹里
比如：D:\chat_logs\张三_聊天记录.txt

然后告诉 skill：
"D:\chat_logs\张三_聊天记录.txt"
```

**方式 E：直接粘贴**
```
打开 txt 文件 → 全选复制 → 粘贴到终端/对话框中
适合聊天记录不太长的情况（< 几万字）
```

**提示**：
- 聊天记录**越长越好**——几百条以上的对话才能提取出稳定的性格特征
- 如果文件太大（>10MB），可以截取最有代表性的片段
- 群聊 + 私聊混合最佳

### Step 3：等待分析（自动化）

skill 会自动运行分析管线：

```
┌─────────────────────────────────────────────┐
│  1. 从聊天记录中提取你同学的所有发言           │
│  2. 分析表达风格：口头禅、高频词、句式、emoji  │
│  3. 分析决策模式：优先级、推进/谨慎的场景       │
│  4. 分析人际行为：对上/对下/对平级的差异        │
│  5. 识别边界和红线                             │
│  6. 组装成 6 层人格架构                        │
│  7. 生成最终文件                               │
└─────────────────────────────────────────────┘
```

### Step 4：检查生成结果

分析完成后会生成以下文件：

```
skills/colleague/{同学拼音}/
├── persona.md      ← 性格（6层架构）
├── work.md         ← 能力/工作风格
└── meta.json       ← 元数据
```

**检查 persona.md**——这是核心，应该包含：

| 层级 | 内容 | 检查要点 |
|:---|:---|:---|
| Layer 0 | 核心性格规则 | 是否准确反映了这个人最本质的特点？ |
| Layer 1 | 身份 | 基本信息是否正确？ |
| Layer 2 | 表达风格 | 口头禅、高频词、说话方式像不像？ |
| Layer 3 | 决策与判断 | 遇到事情的反应模式对不对？ |
| Layer 4 | 人际行为 | 对不同人的态度差异描述准不准？ |
| Layer 5 | 边界与红线 | 什么话题会让他急/不高兴？ |

### Step 5：修正与迭代

如果发现不准的地方，直接告诉 skill：

```
"他的口头禅不是'这个不行'，而是'你在想什么呢'"
"他其实不玩游戏，删掉游戏相关的部分"
"他对领导不是汇报型的，是那种爱答不理的"
```

skill 会自动修正对应的层，并记录到 correction log 中。

## 四、如何使用生成的 Skill

生成的文件可以加载到 AI 助手中。使用场景：

```
场景1：模拟对话
  "用张三的语气跟我说句话"
  → AI 加载 persona.md，模仿张三的表达风格回复

场景2：预判反应
  "如果跟张三提这个方案，他会怎么反应？"
  → AI 根据 Layer 3（决策模式）给出预判

场景3：生成符合风格的文本
  "帮我用张三的风格写一封邮件"
  → AI 按照 persona.md 中的表达规则生成
```

## 六、常见问题

**Q：聊天记录太少怎么办？**
> 至少需要 200+ 条你同学的发言。太少的话分析器提取不出稳定的模式。可以多收集几个群的聊天记录。

**Q：分析结果不准怎么办？**
> 这很正常——微信聊天只是一个人的一部分表现。用 Step 5 的修正功能迭代几轮就好。也可以补充其他材料（比如朋友圈、笔记、共同经历的回忆）。

**Q：可以同时做几个人的 skill 吗？**
> 可以。每个人独立一个目录：`skills/colleague/zhangsan/`、`skills/colleague/lisi/`。

**Q：需要联网吗？**
> 分析管线本身不需要联网（本地 prompt 模板 + LLM 推理）。但如果你用的是在线 LLM API（如 Claude API），则需要网络。

## 七、文件结构速查

```
colleague-skill/
├── SKILL.md                    ← 主入口（告诉 AI 怎么用这个工具）
├── prompts/
│   ├── intake.md               ← 3个问题的模板
│   ├── persona_analyzer.md     ← 从原始材料提取性格特征
│   ├── persona_builder.md      ← 组装成6层人格
│   ├── merger.md               ← 增量合并新内容
│   ├── correction_handler.md   ← 处理"你说错了"的修正
│   ├── work_analyzer.md        ← 提取工作能力
│   └── work_builder.md         ← 生成 work.md
├── tools/
│   ├── skill_writer.py         ← 主工具（create/update/list）
│   ├── skill_schema.py         ← 元数据 schema
│   └── skill_presets.py        ← 预设配置
└── skills/colleague/           ← 生成的 skill 存放位置
    ├── example_zhangsan/       ← 示例：字节后端
    ├── example_tianyi/         ← 示例：AI安全工程师
    └── example_jiaxiu/         ← 示例：HRBP
```
