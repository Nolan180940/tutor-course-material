# 机器学习四大范式：原理详解

---

## 一、分类（Classification）—— "这属于哪一类？"

### 1.1 线性模型：先算一个分数

任何分类器的第一步都一样——先算一个**加权求和**（线性组合）：

$$z = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$$

- $x_1, x_2, \ldots, x_n$：输入特征（比如邮件中"免费"出现次数、"中奖"出现次数、感叹号数量……）
- $w_1, w_2, \ldots, w_n$：每个特征的**权重**（模型要学的参数）
- $b$：偏置项（bias）

**举例**：判断邮件是否是垃圾邮件

```
特征：  "免费"出现次数=3， "中奖"出现次数=1， 感叹号数量=5
权重：  w₁=0.4,  w₂=0.8,  w₃=0.2
偏置：  b = -2

z = 0.4×3 + 0.8×1 + 0.2×5 + (-2) = 1.2 + 0.8 + 1.0 - 2 = 1.0
```

但 $z=1.0$ 是什么意思？是个连续的数字，不是"是/否"。所以我们需要一步变换——

### 1.2 Sigmoid：把任意数字压到 (0, 1)

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

```
z → +∞ 时：σ(z) → 1    （几乎确定是）
z → -∞ 时：σ(z) → 0    （几乎确定不是）
z = 0 时： σ(z) = 0.5   （完全不确定）
```

图像：

```
σ(z)
  1 |              ___________
    |            /
  0.5|          /
    |        /
  0 |_______/
    +---|---|---|---|---→ z
       -3  -1   0   1   3
```

**关键性质**：不管 $z$ 是多少（$-\infty$ 到 $+\infty$），经过 Sigmoid 后都被压到 $(0, 1)$ 之间，可以解释为**概率**。

回到例子：$z=1.0$

$$\sigma(1.0) = \frac{1}{1+e^{-1.0}} = \frac{1}{1+0.368} = 0.731$$

**结论**：模型认为这封邮件有 73.1% 的概率是垃圾邮件。设阈值 0.5，≥0.5 判为垃圾邮件 → **是垃圾邮件**。

### 1.3 损失函数：衡量"错得多离谱"

模型预测的 $0.731$，真实标签是 $1$（确实是垃圾邮件），差多少？

**交叉熵损失（Binary Cross-Entropy）**：

$$L = -\left[ y \cdot \log(\hat{y}) + (1-y) \cdot \log(1-\hat{y}) \right]$$

- $y$：真实标签（0 或 1）
- $\hat{y}$：模型预测的概率

```
如果 y=1（真实是垃圾邮件）：
  L = -log(ŷ)
  
  ŷ=0.99 → L = -log(0.99) = 0.01  ← 预测很准，损失很小
  ŷ=0.73 → L = -log(0.73) = 0.31  ← 有点偏差
  ŷ=0.10 → L = -log(0.10) = 2.30  ← 严重错误，损失很大

如果 y=0（真实是正常邮件）：
  L = -log(1-ŷ)
  
  ŷ=0.01 → L = -log(0.99) = 0.01  ← 预测很准
  ŷ=0.90 → L = -log(0.10) = 2.30  ← 严重错误
```

> **直觉**：预测越离谱，损失越大；预测越准，损失越小。训练目标就是让总损失最小。

### 1.4 梯度下降：怎么调整权重

损失 $L$ 是关于 $w_1, w_2, \ldots, b$ 的函数。要最小化 $L$，就沿着**梯度的反方向**更新参数：

$$w_i \leftarrow w_i - \eta \cdot \frac{\partial L}{\partial w_i}$$

- $\frac{\partial L}{\partial w_i}$：损失对 $w_i$ 的偏导数（梯度）——指明"朝哪个方向调会让损失变大"
- $\eta$：学习率（learning rate）——每次调整的步长

**链式法则**（为什么反向传播能算出梯度）：

$$\frac{\partial L}{\partial w_i} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w_i}$$

```
L（损失）
 ↑ 
 ŷ = σ(z)        ← ∂L/∂ŷ · ∂ŷ/∂z
 ↑
 z = w·x + b     ← ∂z/∂w = x
 ↑
 x（输入特征）
```

**一轮训练的完整过程**：

```
① 前向传播：
   x=3 → z=1.0 → ŷ=σ(1.0)=0.731

② 算损失：
   y=1, ŷ=0.731 → L = -log(0.731) = 0.313

③ 反向传播（算梯度）：
   ∂L/∂w₁ = (ŷ - y) × x₁ = (0.731 - 1) × 3 = -0.807

④ 更新权重（η=0.1）：
   w₁ ← 0.4 - 0.1 × (-0.807) = 0.481
   
   w₁ 变大了 → 下次 z 更大 → ŷ 更接近 1 → 损失更小 ✓
```

> **这就是训练的本质**：前向传播 → 算损失 → 反向传播 → 更新参数 → 重复几百万次 → 模型越来越准。

### 1.5 其他激活函数

Sigmoid 只是**其中一种**把线性输出映射到非线性的方式：

| 激活函数 | 公式 | 输出范围 | 用途 |
|:---:|:---|:---:|:---|
| **Sigmoid** | $\sigma(z)=\frac{1}{1+e^{-z}}$ | $(0,1)$ | 二分类输出层（概率） |
| **Tanh** | $\tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}$ | $(-1,1)$ | 隐藏层（零中心化，比Sigmoid好） |
| **ReLU** | $f(z)=\max(0,z)$ | $[0,+\infty)$ | 隐藏层（计算快，缓解梯度消失） |
| **Leaky ReLU** | $f(z)=\max(0.01z,z)$ | $(-\infty,+\infty)$ | 隐藏层（解决ReLU"死神经元"问题） |

```
Sigmoid:        Tanh:           ReLU:          Leaky ReLU:
 1|     ___       1|  ___         |  /           |  /
  |    /           | /            | /            | /
0.5|  /          0 |/           0 |/____       0 |/______
  | /             | \            |              | /
 0|/___        -1|  ‾‾‾         0|              0|
```

**为什么 ReLU 最常用**：
- Sigmoid/Tanh 在 $z$ 很大或很小时，梯度接近 0 → **梯度消失** → 权重几乎不更新
- ReLU 在 $z>0$ 时梯度恒为 1 → 不会梯度消失 → 训练更快

### 1.6 多分类：Softmax

二分类用 Sigmoid 输出一个概率；多分类用 **Softmax** 输出多个概率（总和为 1）：

$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

```
假设要分3类：猫 / 狗 / 鸟
模型输出的原始分数：z = [2.0, 1.0, 0.1]

Softmax 计算：
  猫：e^2.0 / (e^2.0 + e^1.0 + e^0.1) = 7.39 / 10.46 = 0.706
  狗：e^1.0 / 10.46                       = 2.72 / 10.46 = 0.260
  鸟：e^0.1 / 10.46                       = 1.11 / 10.46 = 0.106

验证：0.706 + 0.260 + 0.106 = 1.072 ≈ 1.0 ✓（浮点误差）

→ 判定为猫（概率最高）
```

> **性质**：Softmax 保证所有输出 >0 且和为 1，可以直接当概率用。输入越大，输出越接近 1。

## 二、回归（Regression）—— "这个值是多少？"

### 2.1 和分类的唯一区别：输出层不加激活函数

```
分类：z → Sigmoid(z) → ŷ∈(0,1)    是概率
回归：z → 直接输出 z   → ŷ∈(-∞,+∞) 是数值
```

### 2.2 线性回归的数学形式

$$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b$$

**损失函数：均方误差（MSE）**

$$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

**梯度**（比分类更简单，因为没有 Sigmoid）：

$$\frac{\partial L}{\partial w_j} = \frac{1}{n}\sum_{i=1}^{n} -2(y_i - \hat{y}_i) \cdot x_{ij}$$

### 2.3 举例：预测房价

```
输入特征：面积=100m², 卧室=2, 楼层=5
真实价格：300万

假设当前模型：ŷ = 3.2×面积 + 15×卧室 + 2×楼层 - 10
= 3.2×100 + 15×2 + 2×5 - 10 = 320 + 30 + 10 - 10 = 350万

预测值 = 350万，真实值 = 300万
MSE损失 = (350-300)² = 2500

反向传播算梯度：
  ∂L/∂w₁ = -2×(300-350)×100 = 10000  → w₁ 要调小
  ∂L/∂b  = -2×(300-350)×1  = 100     → b 要调小

更新后：w₁ 从 3.2 → 3.1（调小了）
下次预测：ŷ = 3.1×100 + ... = 340万 → 更接近300万 ✓
```

### 2.4 回归评估指标

| 指标 | 公式 | 直觉 |
|:---|:---|:---|
| **MSE** | $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ | 平均平方误差（对大误差惩罚重） |
| **RMSE** | $\sqrt{\text{MSE}}$ | 和原始单位一样，好解释 |
| **MAE** | $\frac{1}{n}\sum|y_i-\hat{y}_i|$ | 平均绝对误差（对大误差不敏感） |
| **$R^2$** | $1 - \frac{\sum(y_i-\hat{y}_i)^2}{\sum(y_i-\bar{y})^2}$ | 模型解释了多少变异（1=完美，0=不如猜均值） |

## 三、聚类（Clustering）—— "这些数据能分成几堆？"

### 3.1 核心思想：没有标签，按距离分堆

聚类和分类/回归最大的区别：**没有标签，没有激活函数，没有梯度下降**。它是一种完全不同的范式。

### 3.2 K-Means 算法详解

**目标函数（最小化组内距离之和）**：

$$J = \sum_{k=1}^{K}\sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

- $K$：分几组
- $C_k$：第 $k$ 组的数据点集合
- $\mu_k$：第 $k$ 组的中心点（组内所有点的均值）
- $\|x_i - \mu_k\|^2$：点到中心的欧氏距离的平方

**算法步骤（交替优化）**：

```
Step 1（E步）：固定中心点，把每个点分配给最近的中心
  对每个点 xᵢ：
    计算 xᵢ 到每个中心 μₖ 的距离
    把 xᵢ 分配给最近的那个中心所在的组

Step 2（M步）：固定分组，重新算中心点
  对每个组 Cₖ：
    μₖ = 组内所有点的均值 = (1/|Cₖ|) Σ xᵢ

Step 3：重复 Step 1-2，直到中心点不再移动
```

**具体示例**：

```
原始数据（5个点，2维）：
  A(1,1), B(2,1), C(5,4), D(6,5), E(7,4)

第1轮迭代：
  初始中心：μ₁=(1,1), μ₂=(7,4)

  E步（分配）：
    A: d(A,μ₁)=0, d(A,μ₂)=7.2 → 分配给 μ₁
    B: d(B,μ₁)=1, d(B,μ₂)=6.4 → 分配给 μ₁
    C: d(C,μ₁)=5.0, d(C,μ₂)=2.0 → 分配给 μ₂
    D: d(D,μ₁)=6.4, d(D,μ₂)=1.4 → 分配给 μ₂
    E: d(E,μ₁)=7.2, d(E,μ₂)=0 → 分配给 μ₂

  M步（更新中心）：
    μ₁ = (A+B)/2 = ((1+2)/2, (1+1)/2) = (1.5, 1.0)
    μ₂ = (C+D+E)/3 = ((5+6+7)/3, (4+5+4)/3) = (6.0, 4.33)

第2轮迭代：
  E步（用新中心重新分配）：
    A: d(A,μ₁)=0.7, d(A,μ₂)=6.3 → μ₁
    B: d(B,μ₁)=0.5, d(B,μ₂)=5.5 → μ₁
    C: d(C,μ₁)=4.5, d(C,μ₂)=1.0 → μ₂
    D: d(D,μ₁)=5.9, d(D,μ₂)=0.6 → μ₂
    E: d(E,μ₁)=6.7, d(E,μ₂)=1.0 → μ₂
  → 分配和上一轮一样了 → 收敛！停止。

最终结果：
  群组1：{A, B}，中心=(1.5, 1.0)  ← "左下角的点"
  群组2：{C, D, E}，中心=(6.0, 4.33)  ← "右上角的点"
```

### 3.3 K怎么选？—— 肘部法则（Elbow Method）

$$\text{SSE}(K) = \sum_{k=1}^{K}\sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

```
SSE
  |
  |\
  | \
  |  \____    ← 这里是"肘部"（拐点）
  |       \_______
  +--|---|---|---|---→ K(组数)
    2   3   4   5

K=3 时 SSE 急剧下降，之后变缓 → 选3组最合适
```

### 3.4 DBSCAN：基于密度的聚类

K-Means 假设数据是"圆形"的群组，但现实数据可能是任意形状。DBSCAN 按**密度**来划分：

**两个核心参数**：
- $\varepsilon$（epsilon）：邻域半径
- $\text{MinPts}$：最少需要多少个点才算一个密集区域

```
核心概念：
  核心点：ε 邻域内至少有 MinPts 个点
  边界点：ε 邻域内点数 < MinPts，但在某个核心点的邻域内
  噪声点：既不是核心点也不是边界点 → 被丢弃

聚类过程：
  从一个核心点出发 → 把它 ε 邻域内的所有点归为一类
  → 如果邻域内还有核心点 → 继续扩展
  → 直到无法再扩展 → 一个簇形成
```

```
          ·  ·              · · ·
        ·  ●  ·            ·  ●  ·
          ·  ·              · · ·
       [核心点●]           [核心点●]
          ·  ·              · · ·
            ·
            · ← 边界点
            ·
              · ← 噪声点（不属于任何簇）

DBSCAN 能发现任意形状的簇（环形、月牙形等），K-Means 做不到
```

## 四、降维（Dimensionality Reduction）—— "300维太高了，能不能压到2维？"

### 4.1 为什么需要降维？

```
词向量空间：每个词有300个维度
人类最多能直观理解3维（x, y, z）
→ 需要从300维 → 2维，才能画图可视化

同时：300维中有大量冗余（维度间有相关性）
→ 去掉冗余维度，不丢失关键信息
```

**维度灾难**：维度越高，数据越稀疏，距离计算越不可靠，模型越容易过拟合。

### 4.2 PCA（主成分分析）详解

**核心思想**：找到数据**变化最大的方向**，只保留这些方向。

**目标函数**：最大化投影后的方差

$$\text{最大化 } \mathbf{w}^T \mathbf{S} \mathbf{w} \quad \text{约束条件 } \|\mathbf{w}\|=1$$

- $\mathbf{w}$：投影方向（主成分方向）
- $\mathbf{S}$：数据的协方差矩阵

**算法步骤**：

```
Step 1：对数据做中心化（每个特征减去均值）
  xᵢ' = xᵢ - μ

Step 2：计算协方差矩阵
  S = (1/n) X'ᵀ X'

Step 3：对协方差矩阵做特征值分解
  S = VΛVᵀ

  特征值 λ₁ ≥ λ₂ ≥ ... ≥ λₙ
  对应的特征向量 v₁, v₂, ..., vₙ

Step 4：选前 k 个特征值对应的特征向量
  信息保留率 = (λ₁+...+λₖ) / (λ₁+...+λₙ)
  
  例：λ₁=5.2, λ₂=2.1, λ₃=0.3, λ₄=0.1
  保留前2个：(5.2+2.1)/(5.2+2.1+0.3+0.1) = 94.7%
```

**几何直觉**：

```
原始数据（2维）：
  
  y |    · ·
    |  · · · ·     ← 数据像一条斜着的椭圆
    | · · · · ·
    |· · ·
    +---|---|---→ x

PCA做的事：
  1. 找到数据变化最大的方向 → 主成分1（PC1）
     这个方向上数据最分散（方差最大）
  2. 找到和PC1垂直的次大方向 → 主成分2（PC2）

降维到1维：
  只保留PC1，扔掉PC2
  所有点投影到PC1这条线上
  
  | · · · · · · ·  ← 信息损失很小（PC1已包含大部分变化）
  +----------------→ PC1
```

**具体数值示例**：

```
数据（2维，3个样本）：
  样本1: (2, 3)
  样本2: (3, 5)
  样本3: (5, 7)

Step 1：中心化
  μ = ((2+3+5)/3, (3+5+7)/3) = (3.33, 5.0)
  X' = [(-1.33, -2.0), (-0.33, 0.0), (1.67, 2.0)]

Step 2：协方差矩阵
  S = X'ᵀ X' / 3 = [[1.56, 2.11], [2.11, 2.89]]

Step 3：特征值分解
  λ₁ = 4.45, v₁ = (0.55, 0.83)  ← PC1方向
  λ₂ = 0.00, v₂ = (-0.83, 0.55) ← PC2方向

  信息保留率 = 4.45/(4.45+0.00) = 100%
  → 第二维完全是冗余的！（数据几乎完全在一条直线上）

Step 4：投影到PC1
  样本1 → 投影值 = (-1.33)×0.55 + (-2.0)×0.83 = -2.38
  样本2 → 投影值 = (-0.33)×0.55 + (0.0)×0.83 = -0.18
  样本3 → 投影值 = (1.67)×0.55 + (2.0)×0.83 = 2.58

→ 3维数据 → 1维，保留100%信息
```

### 4.3 t-SNE：非线性降维

PCA 是**线性**降维（只能投影到直线/平面），t-SNE 是**非线性**降维，擅长保留**局部邻近关系**。

**核心思想**：

```
高维空间：计算点与点之间的"相似度"（用高斯分布）
低维空间：计算点与点之间的"相似度"（用t分布）

优化目标：让低维空间的相似度分布尽量接近高维空间的

→ 高维中离得近的点，低维中也离得近
→ 高维中离得远的点，低维中也离得远
```

**为什么用 t 分布而不用高斯分布**：

```
高维空间中：相似度用高斯分布 p(j|i) = exp(-||xᵢ-xⱼ||²/2σᵢ²)

问题：如果低维也用高斯分布，会出现"拥挤问题"（crowding problem）
  高维空间中有大量中等距离的点
  但低维（2D）空间中放不下这么多中等距离的点

解决：低维用 t 分布（尾部更厚）
  t分布在远距离处衰减更慢 → 允许远距离的点在低维中散得更开
```

**具体步骤**：

```
Step 1：高维空间中，为每个点 xᵢ 计算条件概率 p(j|i)
  p(j|i) = exp(-||xᵢ-xⱼ||²/2σᵢ²) / Σ_{k≠i} exp(-||xᵢ-xₖ||²/2σᵢ²)
  
  σᵢ 用困惑度（perplexity）自动确定，通常设为 30-50

Step 2：对称化
  pᵢⱼ = (p(j|i) + p(i|j)) / 2n

Step 3：低维空间中，初始化随机位置 y₁, ..., yₙ
  计算 qᵢⱼ = (1 + ||yᵢ-yⱼ||²)⁻¹ / Σ_{k≠l} (1 + ||yₖ-yₗ||²)⁻¹
  （t 分布的自由度为1，即柯西分布）

Step 4：梯度下降最小化 KL 散度
  C = KL(P||Q) = Σᵢⱼ pᵢⱼ log(pᵢⱼ/qᵢⱼ)
  
  ∂C/∂yᵢ = 4 Σⱼ (pᵢⱼ - qᵢⱼ)(yᵢ - yⱼ)(1 + ||yᵢ-yⱼ||²)⁻¹
  
  更新：yᵢ ← yᵢ - η × ∂C/∂yᵢ

Step 5：重复 Step 4 几百到几千次，直到收敛
```

**和 PCA 的对比**：

| | PCA | t-SNE |
|:---:|:---|:---|
| **类型** | 线性降维 | 非线性降维 |
| **保留** | 全局结构（方差最大方向） | 局部邻近关系 |
| **速度** | 快（特征值分解，一次计算） | 慢（迭代优化，几百次） |
| **可逆性** | 可以逆变换回高维 | 不可逆 |
| **用途** | 数据压缩、去冗余 | 可视化、探索性分析 |
| **超参数** | 无（除选择保留维度k） | 困惑度（perplexity） |

### 4.4 降维的应用场景

```
1. 可视化：300维词向量 → 2D散点图
   "猫"→[0.82, -0.15], "狗"→[0.79, -0.12], "量子"→[-0.45, 0.67]
   → 在图上看到"猫""狗"挨在一起，"量子"在远处

2. 数据压缩：图像压缩
   原始：100×100像素 = 10000维
   PCA保留前50个主成分 → 压缩到50维，保留95%信息

3. 去噪：去掉方差小的方向（通常是噪声）
   保留方差大的主成分 → 去除高频噪声

4. 特征提取：为后续模型提供更好的输入
   高维稀疏特征 → 低维稠密特征 → 分类/聚类效果更好
```

## 五、四大范式对比总览

| | 分类 | 回归 | 聚类 | 降维 |
|:---:|:---|:---|:---|:---|
| **核心问题** | 属于哪一类？ | 值是多少？ | 能分几堆？ | 能压缩吗？ |
| **输出** | 离散类别 | 连续数值 | 簇标签 | 低维向量 |
| **训练方式** | 梯度下降 | 梯度下降 | 交替迭代 | 特征值分解/优化 |
| **损失函数** | 交叉熵 | MSE | 组内距离之和 | 方差最大化/KL散度 |
| **有无标签** | 有 | 有 | 无 | 无 |
| **激活函数** | Sigmoid/Softmax | 无 | 无 | 无 |
| **代表算法** | Logistic/SVM/决策树 | 线性回归/岭回归 | K-Means/DBSCAN | PCA/t-SNE |
| **数学本质** | 学习决策边界 | 拟合函数 | 最小化簇内距离 | 最大化方差/保留局部结构 |

## 六、它们如何串联起来？

```
实际应用中的流程：

  原始数据（高维、无标签）
        │
        ↓  PCA/t-SNE 降维
  低维数据（去噪、去冗余）
        │
        ├──→ 聚类（发现自然分组）
        │        │
        │        ↓  给聚类结果打标签
        │    有标签数据
        │        │
        │        ↓  分类/回归训练
        │    训练好的模型
        │        │
        │        ↓  预测新数据
        │    预测结果
        │
        └──→ 直接训练分类/回归模型
                 │
                 ↓
             预测结果
```

> **一句话总结**：降维是预处理（压缩数据），聚类是探索（发现结构），分类和回归是预测（做出判断）。它们不是互斥的，而是经常组合使用。
