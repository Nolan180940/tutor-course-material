# 🖥️ 命令行速查表（PowerShell 最简用法）

> 以下命令在 PowerShell 中全部可用。CMD 和 Bash 的常用写法 PowerShell 都认。

---

## 一、每天必用的 10 个命令

```powershell
# 1. 我在哪？
pwd                          # 显示当前路径

# 2. 这里有什么？
ls                           # 列出文件和文件夹

# 3. 进入文件夹
cd 文件夹名                    # 进入
cd ..                         # 返回上一级
cd ~                          # 回到用户主目录

# 4. 创建文件夹
mkdir 新文件夹名

# 5. 创建文件（写入内容）
echo 你好 > hello.txt         # 覆盖写入（文件不存在会自动创建）

# 6. 查看文件内容
cat hello.txt

# 7. 追加内容
echo 第二行 >> hello.txt      # >> 是追加，> 是覆盖

# 8. 复制
cp hello.txt backup.txt

# 9. 重命名 / 移动
mv old.txt new.txt            # 重命名
mv file.txt ../               # 移到上级目录

# 10. 删除
rm file.txt                   # 删文件
rm -r 文件夹名                 # 删文件夹（危险！不进回收站）
```

## 二、更多常用命令

```powershell
# 清屏
cls                           # 也可以用 clear

# 帮助
help 命令名                    # 或: 命令名 --help

# 创建空文件（不写入内容）
touch new.txt                 # 等价于 New-Item new.txt

# 查看进程
ps                            # 列出所有程序

# 查看日期
date                          # 等价于 Get-Date

# 查看 IP 地址
ipconfig                      # 只显示 IPv4: ipconfig | grep IPv4

# 测试网络连通
ping baidu.com

# 下载网页内容
curl https://example.com      # 等价于 Invoke-WebRequest
```

## 三、管道和重定向（这才是精髓）

```powershell
# 管道 |  把左边命令的输出 喂给 右边命令
ls | grep ".txt"              # 列出文件 → 只显示含 .txt 的
ps | grep "chrome"            # 所有进程 → 只显示 chrome

# 重定向 > 和 >>
echo hello > file.txt         # 输出到文件（覆盖）
echo world >> file.txt        # 输出到文件（追加）
ls > 文件列表.txt              # 把 ls 的结果保存到文件
```

## 四、grep — 文本搜索之王

```powershell
grep "关键词" 文件名            # 搜索文件中的关键词
grep -n "关键词" 文件名         # 显示行号
grep -i "关键词" 文件名         # 忽略大小写
grep -c "关键词" 文件名         # 统计出现次数

# 和管道配合最常用
cat app.log | grep "ERROR"    # 日志中找 ERROR
ls | grep ".txt"              # 找所有 txt 文件
ps | grep "python"            # 找 python 进程
```

## 五、实战练习：搭建一个博客项目 🏗️

> 跟着敲一遍，每行都自己打，自然的肌肉记忆。

```powershell
# ═══ 第一步：确认位置，创建项目 ═══
pwd                                    # 看看自己在哪
cd ~                                   # 回到用户主目录（保险起见）
mkdir my-blog                          # 创建博客项目文件夹
cd my-blog                             # 进入项目
pwd                                    # 确认：应该在 .../my-blog

# ═══ 第二步：搭建目录结构 ═══
mkdir src                              # 源代码文件夹
mkdir posts                            # 文章文件夹
mkdir assets                           # 资源文件夹（图片等）

ls                                     # 看看刚建的三个文件夹
# 输出: assets/  posts/  src/

# ═══ 第三步：创建文件 ═══
touch README.md                        # 创建空文件（项目说明）
echo 我的博客 > README.md             # 覆盖写入标题
echo >> README.md                      # 追加空行
echo 欢迎来到我的博客！ >> README.md     # 追加一行

cat README.md                          # 看看写了什么
# 输出:
# # 我的博客
#
# 欢迎来到我的博客！

echo 这是我的第一篇博客文章。 > posts\hello.md   # 创建第一篇文章
echo 这是第二篇文章。 > posts\second.md          # 创建第二篇文章
touch posts\draft.md                              # 创建草稿（空的）

ls posts                                         # 看看 posts 里有什么
# 输出: draft.md  hello.md  second.md

# ═══ 第四步：复制、重命名、移动 ═══
cp README.md assets\README_backup.md             # 备份一份到 assets
ls assets                                        # 确认备份
# 输出: README_backup.md

mv posts\draft.md posts\about.md                 # 草稿写完了，改名为 about

# ═══ 第五步：搜索 — 找出含"博客"的文件 ═══
cat posts\hello.md | grep "博客"                  # 管道 + grep
# 输出: 这是我的第一篇博客文章。

grep "博客" posts\*.md                            # 直接搜所有 md 文件
# 输出: posts/hello.md:这是我的第一篇博客文章。

ls | grep "posts"                                # 管道过滤文件夹名
# 输出: posts

# ═══ 第六步：导出项目快照 ═══
echo === 我的博客项目结构 === > project-tree.txt   # 写入标题
date >> project-tree.txt                          # 追加当前日期
echo >> project-tree.txt                          # 追加空行
ls -R >> project-tree.txt                         # 递归列出所有文件，追加到文件

cat project-tree.txt                              # 看看导出的效果

# ═══ 第七步：清理（假设要删掉备份） ═══
rm assets\README_backup.md                       # 删除备份文件
ls assets                                         # 确认已删除（现在是空的）

# ═══ 最终检查 ═══
cd ..                                             # 回到上级目录
ls my-blog                                        # 看看整个项目的最终结构
# 输出: assets/  posts/  project-tree.txt  README.md  src/
```

## 六、用到的命令清单

| 步骤 | 命令 | 做了什么 |
|:---|:---|:---|
| 导航 | `pwd` `cd` `cd ..` `cd ~` | 确认位置、进出文件夹 |
| 创建 | `mkdir` `touch` `echo >` `echo >>` | 建文件夹、建文件、写内容 |
| 查看 | `ls` `ls -R` `cat` | 列出内容、递归列出、查看文件 |
| 操作 | `cp` `mv` `rm` | 复制备份、重命名、删除 |
| 搜索 | `grep` `\|` | 管道搜索、直接搜索 |
| 导出 | `>` `>>` `date` | 重定向输出、追加、日期 |

---

## 七、三句话总结

| 你想做什么 | 输入什么 |
|:---|:---|
| 看/进/退 | `ls` `cd xxx` `cd ..` |
| 创建/看/写 | `mkdir` `cat` `echo xxx > file` |
| 复制/移动/删除 | `cp` `mv` `rm` |
| 搜索/过滤 | `grep` `\|` |
| 忘了怎么用 | `命令 --help` |

> 🎯 就这些，日常够用了。忘了敲 `--help`，别背。先在 `mkdir test` 里练，别在重要目录玩 `rm`。
