# Markdown 语法速查

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 文本样式

```markdown
*斜体* 或 _斜体_
**粗体** 或 __粗体__
***粗斜体***
~~删除线~~
`行内代码`
<u>下划线</u>
```

## 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 子项目
- 项目三
```

### 有序列表

```markdown
1. 第一项
2. 第二项
3. 第三项
```

## 链接与图片

```markdown
[显示文本](https://example.com)
![图片alt](图片url)
```

## 代码块

````markdown
```python
def hello():
    print("Hello, World!")
```
````

## 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
| :----- | :--: | -----: |
| 单元格 | 单元格 | 单元格 |
```

## 引用

```markdown
> 这是一级引用
>> 这是二级引用
```

## 分割线

```markdown
---
```

## 任务列表

```markdown
- [x] 已完成
- [ ] 未完成
```

## 脚注

```markdown
这里需要脚注[^1]

[^1]: 脚注内容
```

## 转义字符

反斜杠转义特殊字符：`\*` `\#` `\[` `\` 等。
