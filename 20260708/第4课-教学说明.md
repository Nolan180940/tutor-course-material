## 🐍 Part 1：变量与输入输出（0-25 min）

> Notebook：`03-Lecture-Variables.ipynb`

### 只讲这些（跟着跑）：

| # | 内容 | 时间 |
|:---:|:---|:---:|
| 1 | 什么是变量：收纳盒比喻 → `name = "小明"` | 5 min |
| 2 | 四种数据类型：str / int / float / bool | 5 min |
| 3 | `input()` — 让程序接收用户输入 | 5 min |
| 4 | `print()` — 输出到屏幕 | 3 min |
| 5 | f-string 格式化：`f"你好{name}"` | 7 min |

### 💡 教学提示：
- 用"收纳盒贴标签"比喻，6年级学生很容易理解
- `=` 不是"等于"，是"赋值"——反复强调
- f-string 是重点，后面 Firecrawl 会用到
- 让学生当场改 `input()` 的内容，互动感强

## 🔥 Part 2：Firecrawl — AI 上网技能（25-70 min）

> Notebook：`firecrawl.ipynb`

### 内容结构：

| 章节 | 内容 | 时间 |
|:---|:---|:---:|
| 1-3 | Firecrawl 是什么、功能总览、准备工作 | 5 min |
| 4 | Scrape — 抓取单个网页（免 key） | 10 min |
| 5 | Search — 搜索网页 + 获取内容 | 10 min |
| 6 | Interact — 操作网页（简要） | 5 min |
| 7 | Crawl / Map — 爬整站（需 key，看代码） | 5 min |
| 8 | 有 Key vs 免 Key 对比 | 3 min |
| 🎮 | 综合实战：Web 信息收集器 | 5 min |
| 📝 | CLI 速查表 + `--help` 完整命令 | 7 min |

### 🔑 关键要点：

- **前半段（免 key）**：Scrape + Search + Interact，直接跑，零摩擦
- **后半段（有 key）**：Crawl + Map + Agent，让学生知道有 key 能做什么
- **CLI 部分**：最后快速过一遍，强调 `--wait`（crawl/agent 异步）
- **Scrape vs requests.get()**：练习1是最好的对比教学点

### 💡 教学提示：
- 先让学生跑"免 key"的 scrape 和 search，立刻有成就感
- 免 key 的 search 返回结构可能变，用 `.get()` 兜底（代码已处理）
- CLI 部分如果时间不够，只演示 scrape、search、agent 三个
- Agent 和 Crawl 是异步的，必须加 `--wait`，否则不返回结果

### 🎯 核心理念：
> Firecrawl = 给 AI 用的"上网技能"。不是教爬虫，是教**如何让程序获取网络信息**。

## 🔭 Part 3：前沿项目巡礼（70-90 min）

> Notebook：`前沿项目巡礼.ipynb`

### 四个项目：

| 项目 | ⭐ | 一句话 |
|:---|:---:|:---|
| OpenCode | 40k+ | 开源版 Claude Code，免费 AI 编程助手 |
| PasteMD | 1.8k+ | 热键粘贴 AI 回复到 Word/Excel |
| MD-to-Word | — | **老师写的！** Markdown 秒变精美 Word |
| Pandoc | 37k | 幕后英雄：万能文档转换器 |

### 三者关系：
```
OpenCode（AI 写内容）→ PasteMD/MD-to-Word（一键转 Word）
                              ↓
                         Pandoc（底层转换引擎）
```

### 老师演示：
1. 打开 MD-to-Word（老师自己的项目）
2. 从 DeepSeek 复制带公式的 Markdown
3. 看智能修复引擎自动修正
4. 一键导出精美 Word 文档
5. 展示 Pandoc 命令行转换

### 💡 教学提示：
- 重点突出"老师自己的项目"，学生会更有兴趣
- Pandoc 部分是核心知识 — 两个工具底层都是它
- 安装和使用 Pandoc 的指令可以直接跑（`pandoc --version` 已确认可用）
- 把三个项目串成"AI 工作流"的故事线

---

## ⚠️ 注意事项

- Firecrawl 免 key 有速率限制，如果请求太频繁可能 429
- CLI 的 `firecrawl` 命令需要 npm 全局安装（或 `npx -y firecrawl@latest`）
- Agent 和 Crawl 一定要加 `--wait`，不加只返回 job ID
- Pandoc 已确认本机可用（`pandoc --version` 正常）
- Search API v2 返回结构不统一，代码已用 `.get()` 兼容
