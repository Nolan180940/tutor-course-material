## 🎮 Part 2：Agent 实战 — 太空侵略者（40-70 min）

> Notebook：`第3课-Agent实战-太空侵略者.ipynb`

### 流程：

| 步骤 | 做什么 | 时间 |
|:---|:---|:---:|
| 🛠️ 准备 | `pip install pygame`，打开 Copilot Chat | 5 min |
| 🤖 生成 | 把完整 Prompt **一次性**发给 Copilot | 5 min |
| ▶️ 跑 | 复制代码到 `main.py` → 运行 | 5 min |
| 🔧 修 | 报错贴回 Copilot → 修好 → 再跑 | 10 min |
| 🎮 调参 | 改外星人数量、速度、血量等 | 5 min |

### 核心理念：
> 不是"学会写 Pygame"，而是**学会让 AI 帮你做任何事**。300行代码一句不用写。

### 调试技巧：
- 报错了？复制错误信息 → 发给 Copilot："帮我修"
- 字体报错 → Agent 会自动换默认字体
- 图片路径报错 → 检查绝对路径
